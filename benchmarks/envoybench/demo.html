    What these scores mean

    Official QASPER Answer F1 (0–100) measures token overlap with the source answer annotations, using the official evaluator on this selected subset. It is separate from provisional AI support reviews and is not a full QASPER leaderboard result. A valid quoted span does not establish that the answer follows from it. AI passes include correct refusals. BM25 refusal counts use exact “unanswerable” submissions and the source answerability labels; they are not AI support judgments. “Not reviewed” means answer support has no review, “Not recorded” means no cost estimate was saved, and dev smoke runs are unscored. Episode time includes the recorded execution setup.

    Evaluation sequence

    1. 01
      Freeze questions and source text

      Record question IDs, paper exclusions, corpus revision, and source hashes before running the candidate models.

    2. 02
      Pair the Qwen base and v5 investigations

      The paired Qwen models use the same paper tools and serving setup. Supplementary models share the questions and tools but differ in provider, context and runtime. Actions and observations are recorded.

    3. 03
      Produce a provisional comparison

      Use deterministic checks for execution and exact spans. A model grader can assess answers against existing QASPER references, but its verdicts are not independent human judgments.

    4. 04
      Inspect failures; optionally validate with people

      Show paired answers and trajectories. If a human-reviewed result is needed, validate source references first, then judge anonymous answers before revealing model identities.
