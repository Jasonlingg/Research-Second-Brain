An MCP server for ML research

Search arXiv, read paper passages and recall your past experiments through one MCP server. Research Second Brain keeps source-linked notes, results and decisions locally, with a linked reading view in Obsidian.

Setup

Core tools need no GPU or model API key. Paper searches use the public network.

Included features

  • arXiv search and reading — Find papers, follow available citations, cache paper text and inspect exact passages
  • Research memory — Import selected Markdown or JSON notes and search saved experiments across sessions
  • Evidence-linked records — Save findings, results and decisions with source references and revision history
  • Memory review — Ask your assistant to check past records against their sources and draft a proposed update
  • Obsidian export — Browse linked notes refreshed after successful MCP saves; personal notes require explicit import

All included in the same server. Paper search and uncached downloads need internet access. No separate arXiv MCP installation is needed. Review drafts are saved only when explicitly requested.

Save something you read, find it when you need it

Share a paper, article or LinkedIn post with your connected assistant. Include the relevant text or a screenshot if the link is inaccessible.

Now: “Save this runtime comparison as a research note for our paper extractor. Keep the source link, why it might matter and what needs checking.”

Later: “What did we save about encoder runtimes, and does it apply to this experiment?”

Your assistant reads the source and explicitly saves a note through MCP. arXiv tools are included; general web reading uses your assistant's own tools. Notes stay local and can be browsed in Obsidian. Saved claims remain unreviewed until checked.

Run the MCP server

Run Research Second Brain locally and connect it to an MCP client. Your assistant can find past attempts, inspect papers, and save research records. Successful saves refresh a linked Obsidian reading vault.

Installation and client configuration

Run from the repository root

python -m pip install -e '.[mcp,vault]'
python scripts/mcp/research_justification_mcp.py

The second command is the stdio server your client launches.

Current limitations

Recall currently uses word overlap. Exact quotes and hashes establish provenance, not whether a conclusion is supported. Personal Obsidian notes do not sync back into recall. A small pilot did not establish an advantage over web research plus Markdown.
