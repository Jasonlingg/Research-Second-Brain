An MCP server for ML research

Envoy stores experiment results, paper references and research decisions locally. An assistant connected through MCP can search those records, inspect sources and save updates. You can also browse the records in Obsidian.

Setup

Core tools need no GPU or model API key. Paper searches use the public network.

Run the MCP server

Run Envoy locally and connect it to an MCP client. Your assistant can find past attempts, inspect papers, and save research records. Successful saves refresh a linked Obsidian reading vault.

Installation and client configuration

Run from the repository root

python -m pip install -e '.[mcp,vault]'
python scripts/mcp/research_justification_mcp.py

The second command is the stdio server your client launches.

Current limitations

Recall currently uses word overlap. Exact quotes and hashes establish provenance, not whether a conclusion is supported. Personal Obsidian notes do not sync back into recall. A small pilot did not establish an advantage over web research plus Markdown.
